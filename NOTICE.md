## What this repository contains

- Source code for a local RAG / optional fine-tune CLI
- Configuration templates and documentation

## What this repository does NOT contain

- General Conference talk full texts
- Come, Follow Me manuals
- Modern Church edition apparatus (footnotes, Topical Guide, chapter headings as published)
- Built vector indexes, embedding caches, or fine-tuned weights derived from restricted material
- Scraped dumps from churchofjesuschrist.org

Those materials, if used at all, live only on the user's machine under gitignored
`data/raw/user/` (bring-your-own-files) and must never be committed or redistributed
via this repo.
